# LibreAgents UI AppCard smoke app

This public development fixture uses the LibreAgents UI v1 page layout format (text, image, button). It proves AppCard publication, Dashboard discovery, and launch on the local designated Docker server. It contains no user site, private repository, credential, or customer content. The Docker base image is pinned by digest. Production AppCards require a governed, immutable build artifact and the full AVPlatform container admission policy.
